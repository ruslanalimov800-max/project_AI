## Структура

Один текстовый файл `data/raw/sms_dataset/SMSSpamCollection`, кодировка **UTF-8**, на каждой строке: `метка<TAB>текст`.

| Столбец после загрузки | Тип | Описание |
|---|---|---|
| `id` | int64 | порядковый номер строки в исходном файле |
| `text` | object | текст SMS |
| `label` | int64 | целевая переменная: 0 — ham, 1 — spam |

Контрольная сумма SHA-256 исходного файла (477 907 байт): `7d039a24a6083ed9ef0f806ebad56bbb976e3aeb8de05669173bfdc4996c239d`. Исходный файл не изменяется.

## Особенности чтения (проверены тестами `tests/test_load_sms.py`)

* **Кодировка.** Файл декодируется как UTF-8 строго; чтение как latin-1 превращает «£» в «Â£» и ломает токен `<money>`.
* **Кавычки.** В текстах встречаются одиночные `"`; при обычном разборе CSV такие строки склеиваются с соседними (теряются 2 сообщения). Используется `quoting=csv.QUOTE_NONE`, число строк сверяется с файлом.
* В некоторых сообщениях сохранены HTML-сущности (`&lt;#&gt;`, `&amp;`); они раскрываются в предобработке.

## Собственный тестовый набор `data/raw/custom_ru_kk.csv`

* 150 искусственных SMS: 100 на русском и 50 на казахском, по 75 мошеннических и безопасных (по 50/50 в каждом языке);
* столбцы: `id`, `text`, `label` (0 — safe, 1 — fraud), `language`, `annotation_author`, `synthetic`;
* **автор разметки:** сообщения составлены по шаблонам командой проекта (поле `annotation_author`); студенту рекомендуется заменить значение на своё имя;
* реальных номеров телефонов, карт и персональных данных нет; ссылки только на зарезервированные домены `.example`;
* тексты шаблонны (повторяющиеся конструкции), поэтому набор годится для проверки работы и ориентировочной оценки, а **не** как независимая статистически надёжная выборка. Повторов текста нет (проверяется тестом).

## Назначение

SMS Spam Collection — обучение и оценка SMS-модели. Собственный набор RU/KK используется **только для тестирования многоязычности** (задание 8) и в обучении не участвует. Поддержка русского и казахского языков не заявляется, пока Recall мошеннического класса на этом наборе не достигнет 0,80.
