# Статус реализации проекта SMS Guard

Проект приведён в соответствие с требованиями ТЗ:

1. **Данные и датасеты**
   - Подготовлен `data/raw/custom_ru_kk.csv` (150 синтетических SMS: 100 RU, 50 KK, 50% мошеннических, без реальных ПДн).
   - Подготовлены `data/processed/sms_clean.csv` и `data/processed/url_features.parquet` (60 000 URL из PhiUSIIL + Malicious URLs с разделением по доменам без утечки).
2. **ML-модели и правила**
   - Обучена и сохранена модель SMS (`ml/artifacts/sms_model.joblib`, LinearSVM).
   - Обучена и сохранена модель URL (`ml/artifacts/url_model.joblib`, RandomForest).
   - Реализован rule-based анализатор (`ml/rules.py`, 8 групп на RU/KK/EN) и скоринг риска (`ml/risk.py`, `risk_config.yaml`).
   - Единый анализатор (`ml/analyzer.py`) и кэширующий загрузчик (`ml/predictor.py`).
3. **Веб-приложение и REST API**
   - Реализованы веб-страницы (проверка SMS, проверка URL, история, детали, дашборд, статистика, профиль, вход/регистрация).
   - Реализован REST API `/api/v1/...`, валидация, маскирование чувствительных данных, rate limit 30/мин, блокировка входа 5 попыток/60с.
4. **Тесты**
   - Автотесты в `tests/` покрывают загрузку данных, предобработку, признаки SMS/URL, расчёт риска, веб-страницы и REST API.
