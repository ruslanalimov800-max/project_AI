## Воспроизводимые результаты SMS

Выбор модели выполнен на validation; test не использовался для подбора. См. `docs/08_SMS_MODEL_COMPARISON.md` и `ml/artifacts/sms_model_comparison.json`.

## Невыполненное / требующее внешних данных

1. URL-модель нельзя считать обученной: исходный датасет URL отсутствует в полученном архиве. Обучение запускается после предоставления CSV с колонками URL и label (`0` — легитимный, `1` — фишинг).
2. Нельзя достоверно указать метрики URL-модели и итоговые метрики на URL test set до обучения на реальном датасете.
3. Нельзя подтвердить `manage.py check`, миграции и Django client tests в этой рабочей среде: Django/DRF не установлены, а установка пакетов недоступна из-за отсутствия сетевого доступа.
4. Результаты SMS относятся к UCI SMS Spam Collection (англоязычный spam/ham), не являются оценкой финансового мошенничества на RU/KK.

Не подменять эти пробелы искусственными данными или выдуманными метриками.
