# Реализация экранов по разделу 9 ТЗ

| Экран | Реализованные элементы |
|---|---|
| 9.1 Вход и регистрация | Логин, пароль, кнопка входа, ссылка регистрации, вывод ошибки неверных данных; остальные рабочие страницы требуют авторизации. |
| 9.2 Dashboard | Боковая навигация, четыре счётчика (всего, безопасные, подозрительные, мошеннические), doughnut-диаграмма категорий, график за 30 дней, последние проверки с цветными метками. |
| 9.3 Проверка SMS | Поле до 1000 символов, счётчик, кнопка проверки, категория/риск, Risk Score, вероятности SMS и URL моделей, URL как неактивный текст, признаки, рекомендация и предупреждение. |
| 9.4 Проверка URL | Отдельная форма URL, предупреждение что ссылка не открывается, домен, результат модели (если модель обучена), таблица извлечённых структурных признаков. |
| 9.5 История | Фильтры дат, типа, категории и риска, таблица результатов, пагинация 20 записей, переход к подробному результату; выборка ограничена текущим пользователем. |

Диаграммы Dashboard используют агрегаты из БД текущего пользователя. Вероятности моделей выводятся из ответа анализатора; если URL-модель не обучена, интерфейс прямо сообщает об отсутствии оценки, а не подставляет фиктивное число. Проверяемые ссылки выводятся обычным текстом, без гиперссылок.

## Ограничения проверки

Python-файлы прошли `compileall`. В среде подготовки архива Django не установлен, поэтому `manage.py check`, миграции и браузерный smoke-test здесь не выполнялись. Их необходимо выполнить в локальном виртуальном окружении после распаковки.
